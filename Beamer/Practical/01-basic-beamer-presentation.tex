\begin{frame}{What is Technical Writing?}
    \begin{itemize}
        \item Technical writing communicates information clearly.
        \item It presents technical ideas in an organized manner.
        \item It is used in reports, documentation and presentations.
    \end{itemize}
\end{frame}
