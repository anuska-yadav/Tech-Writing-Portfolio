# LaTeX Practical Work

This directory contains practical exercises covering LaTeX document creation, mathematical typesetting, tables, lists, figures and document organization.

---

## Practical Exercises

Each practical is identified by a two-digit sequence number followed by its topic.

The `.tex` source file and its corresponding `.pdf` output use the same base filename.

| No. | Practical | Description |
|:---:|---|---|
| 01 | `01-first-latex-document` | Basic LaTeX document creation and bibliography citation |
| 02 | `02-mathematical-typesetting` | Mathematical expressions and equations |
| 03 | `03-mathematical-structures-and-tables` | Mathematical structures and table creation |
| 04 | `04-lists-colours-and-figures` | Lists, colours and figure insertion |
| 05 | `05-document-structure-and-index` | Document organization and index creation |
