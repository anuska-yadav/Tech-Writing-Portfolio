# LaTeX Practical Work

Each practical is named with a two-digit sequence number followed by its topic.

For every practical, the `.tex` source and its matching `.pdf` output have the same base filename.

- `01-first-latex-document`
- `02-mathematical-typesetting`
- `03-mathematical-structures-and-tables`
- `04-lists-colours-and-figures`
- `05-document-structure-and-index`

`physics.bib` is the bibliography database used with the first document's citation exercise.


The figure practical uses the image files included in this directory: `mnit-logo.png`, `mnit-building.jpg`, `image1.jpg`, and `image2.jpg`. The two additional campus images are illustrative images used for the minipage examples.
