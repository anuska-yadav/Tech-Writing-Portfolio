## Learning Outcomes

After studying this section, I can:

- Explain GitHub and distinguish it from Git.
- Create and manage GitHub repositories.
- Understand public and private repositories.
- Explain the purpose of README files.
- Understand forks and clones.
- Use Issues and Pull Requests for collaboration.
- Explain code reviews and contribution workflows.
- Understand GitHub Projects and Releases.
