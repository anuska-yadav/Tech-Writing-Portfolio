# Introduction to GitHub

## 1. What is GitHub?

GitHub is an online platform used to host Git repositories and support collaboration on projects.

It allows users to store project files online and work together with other contributors.

## 2. Git vs GitHub

Git and GitHub are related, but they serve different purposes.

| Git | GitHub |
|---|---|
| A version control system. | An online hosting and collaboration platform. |
| Tracks changes in project files. | Hosts Git repositories online. |
| Works locally on a computer. | Provides online access to repositories. |
| Manages commits and branches. | Supports collaboration through features such as Pull Requests and Issues. |

## 3. Main Features of GitHub

The Git lecture introduces several GitHub features:

- **Repositories:** Store project files and their version history.
- **Issues:** Discuss and track bugs, tasks and improvements.
- **Pull Requests:** Propose changes and request their review.
- **Actions:** Support repository workflows.
- **Projects:** Organize and track project work.
- **Settings:** Manage repository configuration.

## 4. GitHub Interface

A GitHub repository provides different sections for managing project work.

| Section | Purpose |
|---|---|
| Code | Displays repository files and folders. |
| Issues | Displays discussions and reported tasks. |
| Pull Requests | Displays proposed changes. |
| Actions | Provides access to repository workflows. |
| Settings | Contains repository configuration. |

## 5. Why Use GitHub?

GitHub helps users:

- Host repositories online.
- Share project work.
- Collaborate with other contributors.
- Review proposed changes.
- Organize tasks and discussions.
- Maintain project documentation.

## 6. Key Takeaway

Git manages version control, while GitHub provides an online platform for hosting repositories and collaborating on projects.
