# Creating and Managing GitHub Repositories

## 1. What is a Repository?

A repository is a storage space for project files and their version history.

GitHub allows users to create repositories online to host and manage their projects.

## 2. Creating a New Repository

Follow these steps:

1. Sign in to your GitHub account.
2. Click the **New repository** option.
3. Enter a repository name.
4. Add an optional description.
5. Choose the repository visibility.
6. Select initialization options if required.
7. Click **Create repository**.

## 3. Repository Visibility

GitHub provides two main visibility options.

| Public Repository | Private Repository |
|---|---|
| Can be viewed by anyone. | Access is restricted to authorized users. |
| Useful for sharing projects publicly. | Useful for projects that should not be publicly accessible. |

## 4. Repository Initialization Options

While creating a repository, GitHub provides options such as:

- **README:** Creates a README file describing the project.
- **.gitignore:** Creates a file specifying files Git should ignore.
- **License:** Adds a license file to the repository.

These options can be selected according to the project's requirements.

## 5. Understanding README.md

A README file introduces a project and provides information about it.

It is generally written in Markdown and displayed on the repository's main page.

A README may contain:

- Project name.
- Project purpose.
- Features.
- Installation instructions.
- Usage instructions.
- Contributors.
- License information.

## 6. Repository Settings

The Settings section provides options for managing repository configuration.

The Git lecture introduces the Settings area as part of the GitHub repository interface.

## 7. Key Takeaway

GitHub repositories provide an online space to store project files and maintain their history. Repository visibility, initialization options and README documentation help organize and present a project.
