# Equations, Citations and Exporting Documents

## 1. Adding Equations

Google Docs provides an equation editor.

To insert an equation, use:

**Insert → Equation**

It supports basic LaTeX-style mathematical notation through its graphical interface.

This is useful when preparing mathematical and technical documents.

## 2. Adding Code Snippets

Code snippets can be included in a document using:

- Preformatted text
- Monospace fonts for inline code

For larger code blocks, third-party add-ons or pasted images can be used.

## 3. Citations and Bibliography

Google Docs provides a built-in citation tool for managing references.

To access it, use:

**Tools → Citations**

The available citation styles covered in the lecture are:

- MLA
- APA
- Chicago

Users can add sources, insert in-text citations and automatically generate a bibliography.

Citation managers such as Zotero and Mendeley can also be integrated through add-ons.

## 4. Exporting and Publishing Documents

Google Docs allows documents to be downloaded in different formats, including:

- PDF
- DOCX
- ODT
- HTML
- TXT

Documents can also be published to the web for public viewing.

Google Docs integrates with other Google Workspace applications, including Google Slides and Google Sheets.

## 5. Security and Permissions

Google Docs provides document-level access permissions.

The lecture also covers:

- Setting expiration dates for access.
- Removing access to documents.
- Organization-wide sharing policies through Workspace administration.

## 6. Key Takeaway

Google Docs provides tools for adding equations, code snippets, citations and bibliographies. It also supports exporting, publishing and managing document access.
