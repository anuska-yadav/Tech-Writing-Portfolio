# Collaboration, Sharing and Version History

## 1. Collaboration in Google Docs

Google Docs allows multiple users to work on the same document simultaneously.

Users can see live cursors and changes made by other collaborators.

This makes it useful for group assignments and shared documents.

## 2. Sharing a Document

To share a document, click the **Share** button and invite collaborators through their email address or a link.

Different access permissions can be assigned:

| Permission | Access |
|---|---|
| Viewer | Can view the document |
| Commenter | Can view and add comments |
| Editor | Can make changes to the document |

## 3. Comments and Suggestions

Google Docs provides tools for reviewing and discussing document content.

- **Comments:** Allow collaborators to provide feedback.
- **Resolve comments:** Mark discussions as completed.
- **Assign comments:** Direct a comment or task to a collaborator.
- **Suggesting mode:** Allows proposed edits to be reviewed before they become part of the document.
- **Integrated chat:** Supports live discussions while collaborating.

## 4. Version History

Google Docs automatically saves changes made to a document.

Version history allows users to:

- View earlier versions of a document.
- Track changes over time.
- Restore a previous version when required.
- Name specific versions for important milestones, such as submission or approval.

### Accessing Version History

Open:

**File → Version history**

From there, users can view and restore earlier versions.

## 5. Practical Application

In the lecture activity, we were asked to:

1. Create a Google Doc.
2. Share it with a classmate using edit or suggest access.
3. Try headings, comments and suggestions.
4. Add a table and insert an image or diagram.
5. Review version history and restore an earlier version.

## 6. Key Takeaway

Google Docs supports teamwork through real-time collaboration, sharing permissions, comments, suggestions and version history.
