# Creating and Formatting Documents in Google Docs

## 1. Creating a Document

Google Docs allows users to create documents in two ways:

- Start with a new blank document.
- Use a built-in template, such as a report, meeting notes or manual.

Templates provide a starting structure and help maintain consistency.

## 2. Structuring a Document

A document can be organized using:

- Headings and paragraph styles
- Tables
- Lists
- Images
- Footnotes
- Equations

Using these elements makes information easier to read and understand.

## 3. Paragraph Styles and Hierarchy

Google Docs provides different paragraph styles, including:

| Style | Purpose |
|---|---|
| Title | Main document title |
| Subtitle | Supporting title |
| Heading 1 | Main sections |
| Heading 2 | Subsections |
| Normal Text | Regular paragraph content |

### Why are styles important?

- They maintain consistent formatting.
- They help organize document sections.
- They allow an automatic table of contents to be generated.
- They improve accessibility and document exporting.

## 4. Images and Drawings

Google Docs allows users to insert images from:

- Computer uploads
- Camera
- Web
- Google Drive
- Google Photos

The built-in Drawing tool can also be used to create simple diagrams using shapes and arrows.

## 5. Tables and Lists

Tables help organize information and compare different items.

Lists provide a structured way to present information.

Google Docs supports:
- Bulleted lists
- Numbered lists
- Checklists

## 6. Templates and Formatting Tools

Google Docs provides built-in templates for reports and project proposals.

Other formatting tools covered in the lecture include:

- Headers and footers
- Page numbering
- Find and replace
- Spelling and grammar checking
- Autocorrect suggestions

## 7. Key Takeaway

Proper document structure and formatting make documents consistent, organized and easier to understand. Paragraph styles are especially useful for maintaining hierarchy and generating a table of contents.
