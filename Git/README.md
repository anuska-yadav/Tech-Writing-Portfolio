## Learning Outcomes

After studying this section, I can:

- Explain version control and the purpose of Git.
- Initialize and configure a Git repository.
- Track, stage and commit changes.
- Inspect repository status and commit history.
- Compare, rename, remove and restore files.
- Connect a local repository to GitHub.
- Push, pull, fetch and clone repositories.
- Create, switch, merge and delete branches.
- Understand merge conflicts and their resolution.
- Explain GitHub collaboration features.
- Use tags, releases and rebase.
