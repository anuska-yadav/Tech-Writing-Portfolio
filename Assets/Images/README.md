# Assets — Images

This folder contains six original educational workflow diagrams for the Technical Writing portfolio.

- `latex-workflow.png` — LaTeX source-to-PDF compilation flow
- `beamer-structure.png` — organisation of a Beamer presentation into frames
- `doxygen-workflow.png` — source comments and Doxyfile to generated HTML documentation
- `google-docs-workflow.png` — document sharing, review, and version history
- `git-workflow.png` — working directory, staging area, local repository, and remote repository
- `github-workflow.png` — clone/pull, edit/commit, and push workflow
