# Assets – Supporting Visual Materials

This directory contains visual resources used throughout the Technical Writing portfolio, including diagrams, illustrations and screenshots of practical work.

---

## Folder Structure

### Images

Contains diagrams, illustrations and other visual materials used in documentation and practical work.

### Screenshots

Contains screenshots demonstrating practical execution, software interfaces, generated outputs and completed work.

---

## Purpose

The Assets directory helps organize and maintain visual resources separately from the subject documentation and practical files.

It provides a common location for images and screenshots referenced throughout the portfolio.
