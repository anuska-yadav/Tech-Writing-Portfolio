# Doxygen Documentation Notes

The project source demonstrates the tags explicitly requested in the Doxygen lab:

- `\file` — documents a source file.
- `\mainpage` — defines the main project documentation page.
- `\class` and `\brief` — document classes and their short descriptions.
- `\details` — provides a longer class description.
- `\enum` — documents the `LogLevel` enumeration.
- `\param` — explains function parameters.
- `\return` — explains a function's return value.
- `\todo` — records a task that remains to be addressed.

Both `@` and `\` command styles are valid Doxygen comment styles; this practical uses the backslash form consistently.
