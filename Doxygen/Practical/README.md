# Doxygen Practical Work

This practical demonstrates how Doxygen can be used to generate structured software documentation directly from source-code comments in a multi-file C++ project.

---

## 01 – Logger and Calculation Engine

A multi-file C++ project used to explore Doxygen documentation features, including class descriptions, enumerations, constructors, function parameters, return values and project-level documentation.

### Project Files

- `Logger.h` – Documents the Logger class, `LogLevel` enumeration and constructor.
- `CalculationEngine.h` – Includes class descriptions, function documentation, parameter and return-value descriptions, and a TODO tag.
- `main.cpp` – Contains project-level documentation and the program entry point.
- `Doxyfile` – Contains configuration settings for generating the documentation.

---

## Generate Documentation

Open the Terminal inside the `01-logger-and-calculation-engine/` directory and execute:

```bash
doxygen Doxyfile
```

Doxygen processes the source-code comments and generates documentation according to the configuration settings.

---

## View HTML Documentation

The generated HTML documentation is available in the `generated/html/` directory.

It contains the documentation pages and supporting resources, including stylesheets, JavaScript files and other assets.

To explore the generated documentation, open:

`generated/html/index.html`

The main page provides navigation to the documented classes, source files and other project elements.

---

## Documentation Output

The practical includes the HTML documentation generated by Doxygen. The output can be regenerated whenever the source-code comments or configuration settings are modified.
