# Doxygen Practical Work

This folder contains practical work completed using Doxygen to generate software documentation from C++ source-code comments.

## 01 — Logger and Calculation Engine

This multi-file C++ project follows the Doxygen lab task and demonstrates documentation of classes, enumerations, constructors, functions and project-level information.

### Project Files

- `Logger.h`: Documentation of the Logger class, `LogLevel` enum and constructor.
- `CalculationEngine.h`: Class description, detailed description, power function parameters, return value and TODO tag.
- `main.cpp`: Project main page documentation and program entry point.
- `Doxyfile`: Configuration file specifying HTML, LaTeX and XML documentation output.

### Generate Documentation

Open Terminal in the `01-logger-and-calculation-engine/` directory and run:

```bash
doxygen Doxyfile
```

This generates the documentation according to the settings specified in the Doxyfile.

### View HTML Documentation

The generated HTML documentation is included in this repository inside the `generated/html/` directory.

This directory contains the complete set of files and supporting resources generated by Doxygen, including HTML pages, stylesheets, JavaScript files and other assets.

To view the documentation, open:

`generated/html/index.html`

This opens the main documentation page, from which the documented classes, source files and other sections can be explored.

### Generate LaTeX/PDF Documentation

The assignment also requires LaTeX/PDF output.

After generating the documentation, navigate to the generated LaTeX directory:

```bash
cd generated/latex/
```

Run:

```bash
make
```

This builds the PDF documentation using the generated LaTeX files.

**Note:** PDF generation requires a suitable LaTeX distribution and the necessary build tools to be installed on your system. The generated HTML documentation is included in this repository, while the LaTeX/PDF output can be reproduced using the commands above.
